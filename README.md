# konekt
 KONEKT est un système de billetterie numérique pour la ligne de métro Anyama ↔ Port-Bouët à Abidjan. Les passagers recherchent un voyage, voient l'heure estimée à leur gare spécifique, paient et reçoivent un ticket avec QR Code unique (KNEKT-XXXX). Les agents scannent le QR pour valider le passage en temps réel.
